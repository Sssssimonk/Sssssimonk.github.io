## 1. 数学、概率与统计

| 优先级 | 问题 | 简明答案 |
| --- | --- | --- |
| P0 | 期望、方差和协方差分别表示什么？ | 期望描述随机变量的平均位置；方差衡量自身波动；协方差衡量两个变量共同变化的方向和程度，但其大小受量纲影响。 |
| P0 | 独立与不相关有什么区别？ | 独立意味着联合分布可分解，通常能推出协方差为零；不相关只表示线性关系为零，不能推出独立。联合高斯时二者等价。 |
| P0 | 贝叶斯公式是什么？ | $P(A\mid B)=P(B\mid A)P(A)/P(B)$，用似然与先验更新得到后验。分类中常写成后验正比于似然乘先验。 |
| P0 | 最大似然估计和最大后验估计有何区别？ | MLE 只最大化数据似然；MAP 还乘参数先验。MAP 可看作带正则项的 MLE，例如高斯先验对应 L2 正则。 |
| P0 | 交叉熵与 KL 散度有什么关系？ | $H(p,q)=H(p)+D_{KL}(p\Vert q)$。真实分布 $p$ 固定时，最小化交叉熵等价于最小化 $D_{KL}(p\Vert q)$。 |
| P0 | 中心极限定理说了什么？ | 在一定条件下，大量独立同分布随机变量之和经标准化后趋近正态分布，不要求原变量本身服从正态分布。 |
| P0 | 协方差矩阵为什么一定是半正定的？ | 对任意向量 $v$，$v^T\Sigma v=\mathrm{Var}(v^TX)\ge 0$，所以协方差矩阵半正定。 |
| P1 | 大数定律与中心极限定理的区别？ | 大数定律说明样本均值收敛到总体均值；中心极限定理描述样本均值误差经缩放后的渐近分布。 |
| P1 | 什么是置信区间？ | 它是由随机样本构造的区间；若重复抽样，按该方法构造的区间有指定比例覆盖真参数。不能简单解释为参数有 95% 概率落在已得到的区间内。 |
| P1 | p 值是什么？ | 在原假设成立时，得到当前或更极端统计量的概率。它不是“原假设为真的概率”，也不表示效应大小。 |
| P1 | L1、L2 范数的几何差异是什么？ | L1 约束域有尖角，更容易得到稀疏解；L2 约束域光滑，通常让权重整体缩小但很少精确为零。 |
| P2 | Jensen 不等式在机器学习中有什么用？ | 对凸函数 $f$，$f(E[X])\le E[f(X)]$。它是变分推断中 ELBO、EM 算法和多种损失上界推导的基础。 |

## 2. 机器学习

| 优先级 | 问题 | 简明答案 |
| --- | --- | --- |
| P0 | 监督学习、无监督学习和自监督学习的区别？ | 监督学习使用人工或业务标签；无监督学习发现未标注数据结构；自监督学习从数据自身构造预测目标，再学习可迁移表示。 |
| P0 | 什么是偏差—方差权衡？ | 高偏差通常欠拟合，高方差通常过拟合。模型复杂度增加往往降低偏差、提高方差，目标是最小化泛化误差而非训练误差。 |
| P0 | 如何判断欠拟合和过拟合？ | 训练、验证误差都高通常是欠拟合；训练误差低而验证误差明显高通常是过拟合。应结合学习曲线排查。 |
| P0 | 训练集、验证集和测试集各做什么？ | 训练集拟合参数；验证集选模型和超参数；测试集只做最终无偏评估。反复看测试集会造成测试集泄漏。 |
| P0 | 为什么要做交叉验证？ | 它用多次划分降低单次验证结果的偶然性，适合数据较少时估计泛化能力；时间序列必须按时间切分，不能随机打乱。 |
| P0 | Precision、Recall、F1 分别是什么？ | Precision=$TP/(TP+FP)$；Recall=$TP/(TP+FN)$；F1 是二者调和平均。误报代价高重 Precision，漏报代价高重 Recall。 |
| P0 | ROC-AUC 与 PR-AUC 怎么选？ | ROC-AUC 衡量整体排序，类别极不均衡时可能显得乐观；PR-AUC 更关注正类识别，稀有正类任务通常更有解释力。 |
| P0 | 生成式模型与判别式模型的区别？ | 生成式模型学习 $p(x,y)$ 或 $p(x)$，可生成或补全数据；判别式模型直接学习 $p(y\mid x)$ 或决策边界。 |
| P0 | 线性回归有哪些基本假设？ | 常见假设包括线性关系、误差独立、同方差、无严重多重共线性；正态误差主要用于小样本统计推断，不是得到最小二乘解的必要条件。 |
| P0 | 逻辑回归为什么叫“回归”？ | 它对类别的对数几率做线性回归，再经 sigmoid 映射成概率，本质是线性判别分类器。 |
| P0 | 逻辑回归的损失为什么用交叉熵？ | 伯努利分布的负对数似然正好得到二元交叉熵；它可导、凸，并会对自信的错误预测施加强惩罚。 |
| P0 | 决策树如何选择划分特征？ | 分类树常最大化信息增益、信息增益率或基尼指数下降；回归树常最小化划分后的平方误差。 |
| P0 | 随机森林和 GBDT 的区别？ | 随机森林并行训练高方差树并平均，主要降方差；GBDT 串行拟合前序残差或负梯度，主要降偏差，通常更依赖调参。 |
| P0 | XGBoost 相比传统 GBDT 的改进？ | 使用一、二阶梯度近似，目标含正则项，支持列采样、缺失值默认方向、并行候选切分及高效工程实现。 |
| P0 | SVM 的核心思想是什么？ | 在特征空间寻找最大间隔超平面；软间隔用松弛变量容忍误分，核技巧通过内积隐式映射到高维空间。 |
| P1 | 为什么 SVM 要转成对偶问题？ | 对偶形式只依赖样本内积，便于使用核函数；当特征维度高于样本数时也可能更易求解，并自然体现支持向量的稀疏性。 |
| P1 | K-means 的步骤和局限是什么？ | 交替进行最近中心分配与均值更新，直到收敛；它对初始值、尺度和异常点敏感，偏好近似球形、方差相近的簇。 |
| P1 | PCA 的目标是什么？ | 找到方差最大的正交方向进行线性投影，等价于在给定维数下最小化平方重构误差；可由协方差矩阵特征分解或 SVD 求得。 |
| P1 | Bagging 与 Boosting 的区别？ | Bagging 对重采样数据并行训练模型再聚合，重点降方差；Boosting 顺序关注前面模型的错误，重点降偏差。 |
| P1 | 类别不平衡如何处理？ | 可重采样、类别加权、阈值移动、使用 focal loss，并选 PR-AUC、F1、Recall 等合适指标；划分数据时需分层。 |
| P1 | 数据泄漏有哪些常见形式？ | 在切分前用全量数据做归一化或特征选择、使用预测时不可获得的未来特征、同一用户样本跨集合、调参时偷看测试集。 |
| P1 | 缺失值如何处理？ | 先判断缺失机制；可删除、常数/统计量/模型插补并增加缺失指示特征。插补器只能在训练集上拟合。 |
| P2 | 模型校准是什么？ | 若预测概率为 0.8 的样本约有 80% 为正类，则概率已校准。可用 reliability diagram、ECE、Brier score 评估，用 Platt scaling 或 isotonic regression 校准。 |
| P2 | 概念漂移与数据漂移的区别？ | 数据漂移是 $p(x)$ 变化；概念漂移是 $p(y\mid x)$ 变化。前者可监测输入分布，后者通常需要延迟标签或代理指标判断。 |

## 3. 深度学习

| 优先级 | 问题 | 简明答案 |
| --- | --- | --- |
| P0 | 反向传播的本质是什么？ | 在计算图上利用链式法则从损失向参数反向传播梯度，并复用中间结果，是反向模式自动微分。 |
| P0 | 梯度消失和梯度爆炸为什么发生？ | 深层链式乘积中 Jacobian 的特征值长期小于或大于 1，使梯度指数衰减或放大；饱和激活和不当初始化会加剧问题。 |
| P0 | 如何缓解梯度消失或爆炸？ | 合理初始化、ReLU 类激活、残差连接、归一化可改善传播；梯度裁剪主要处理爆炸，LSTM/GRU 的门结构缓解长序列问题。 |
| P0 | SGD、Momentum、Adam 的区别？ | SGD 使用当前梯度；Momentum 累积速度以减少震荡；Adam 同时估计梯度一阶、二阶矩并自适应缩放，收敛快但未必泛化最好。 |
| P0 | 学习率为什么重要？常见调度方式有哪些？ | 过大会震荡或发散，过小收敛慢且易停在不佳区域。常用 warmup、step、cosine decay 和 plateau 调度。 |
| P0 | Batch Normalization 与 Layer Normalization 的区别？ | BN 在 batch 维统计每个特征，受 batch 大小影响；LN 在单样本特征维归一化，与 batch 无关，更适合序列模型和 LLM。 |
| P0 | Dropout 为什么能防过拟合？ | 训练时随机屏蔽神经元，减少特征共适应，近似训练多个子网络并做集成；推理时关闭并保持期望尺度一致。 |
| P0 | 为什么需要非线性激活函数？ | 多层线性变换仍等价于单层线性变换；非线性使网络能逼近复杂函数和学习非线性决策边界。 |
| P0 | ReLU 的优缺点是什么？ | 正区间梯度稳定、计算简单且产生稀疏激活；负区间梯度为零可能出现 dead ReLU，可用 Leaky ReLU、GELU 等缓解。 |
| P0 | 权重初始化为什么不能全为零？ | 同层神经元会得到完全相同的梯度，无法打破对称性；Xavier/He 初始化通过控制前向和反向方差改善训练稳定性。 |
| P0 | 残差连接为什么有效？ | 学习 $F(x)$ 后输出 $x+F(x)$，提供恒等信息与梯度通路，使深层网络更易优化并缓解退化问题。 |
| P0 | 卷积相比全连接的优势是什么？ | 局部连接和权重共享显著减少参数，并注入平移等变、局部结构等归纳偏置。 |
| P0 | 感受野是什么？ | 某层一个位置所能依赖的输入区域。堆叠卷积、增大核、步幅、池化或空洞卷积都会扩大感受野。 |
| P1 | 1×1 卷积有什么作用？ | 在每个空间位置进行通道混合，可升降维、增加非线性层，同时保持空间尺寸。 |
| P1 | RNN 为什么难以学习长期依赖？ | 时间展开后反复乘同一类 Jacobian，容易梯度消失或爆炸；顺序计算也难以并行。LSTM/GRU 用门控记忆缓解但不完全消除。 |
| P1 | `model.eval()` 与 `torch.no_grad()` 的区别？ | `eval()` 切换 Dropout、BN 等层的行为；`no_grad()` 关闭梯度记录以省内存。推理时通常二者都要用。 |
| P1 | 为什么交叉熵前通常不手动做 softmax？ | 常见实现把 `log_softmax` 与 NLL 合并，利用 log-sum-exp 提高数值稳定性；输入应直接给 logits。 |
| P1 | 数据增强为什么有效？ | 它把任务已知的不变性注入训练分布，增加有效样本多样性、降低过拟合；增强必须保持标签语义。 |
| P2 | 知识蒸馏是什么？ | 学生模型拟合教师的软分布、隐藏表示或关系结构；温度提高能暴露类别间相对信息，常与真实标签损失联合训练。 |
| P2 | 深度可分离卷积为什么省计算？ | 先逐通道做空间卷积，再用 1×1 卷积混合通道，把普通卷积的通道与空间计算分解。 |

## 4. CV、NLP 与推荐系统

| 优先级 | 问题 | 简明答案 |
| --- | --- | --- |
| P0 | 图像分类、目标检测和语义分割的区别？ | 分类给整图标签；检测输出目标类别和框；语义分割给每个像素分类，同类实例不区分。实例分割还要区分同类不同实例。 |
| P0 | IoU 与 NMS 是什么？ | IoU 是预测框与真值框交并比；NMS 按置信度保留高分框并抑制与其重叠过大的框，减少重复检测。 |
| P0 | Word2Vec 的 CBOW 与 Skip-gram 有何区别？ | CBOW 用上下文预测中心词，训练较快；Skip-gram 用中心词预测上下文，对低频词通常更友好。 |
| P0 | TF-IDF 的直觉是什么？ | 词在当前文档出现越多越重要，但在整个语料越常见区分度越低；因此用词频乘逆文档频率。它忽略词序和深层语义。 |
| P0 | BERT 与 GPT 的预训练目标有什么不同？ | BERT 用双向编码器和掩码语言建模，擅长理解；GPT 用因果掩码做下一 token 预测，天然适合自回归生成。 |
| P0 | 推荐系统为什么常分召回和排序两阶段？ | 召回从海量候选中快速筛出较小集合，追求覆盖；排序使用更丰富特征精排，追求准确，从而兼顾延迟和效果。 |
| P0 | 协同过滤的基本思想是什么？ | 根据用户—物品交互相似性做推荐，可基于邻域或矩阵分解；优点是不依赖内容，缺点是稀疏和冷启动。 |
| P1 | 两阶段与单阶段检测器的区别？ | 两阶段先产生候选区域再分类回归，通常精度高；单阶段直接密集预测，结构更简单、速度通常更快。 |
| P1 | BLEU 与 ROUGE 的区别？ | BLEU 更强调生成与参考文本的 n-gram precision，常用于翻译；ROUGE 更强调 recall，常用于摘要。二者都不充分反映事实性和语义质量。 |
| P1 | 为什么子词 tokenization 常优于纯词或纯字符？ | 它在词表大小、序列长度和未登录词之间折中，常见词可保留整体，稀有词可拆解。常用 BPE、WordPiece、Unigram。 |
| P1 | 推荐系统如何处理冷启动？ | 新用户可用热门、上下文和快速兴趣问答；新物品可用内容特征、探索流量；还可迁移跨域信息或使用多模态表征。 |
| P1 | 常见推荐指标有哪些？ | 离线常用 Recall@K、Precision@K、NDCG、MRR、AUC；在线关注 CTR、转化、留存、时长，同时监控多样性与公平性。 |
| P2 | 双塔模型为何适合召回？ | 用户和物品独立编码，物品向量可预计算并建立 ANN 索引，在线只算用户向量和近邻搜索；代价是交叉特征表达受限。 |

## 5. 强化学习

| 优先级 | 问题 | 简明答案 |
| --- | --- | --- |
| P0 | 强化学习的基本要素有哪些？ | 智能体在状态 $s$ 下按策略选择动作 $a$，环境返回奖励 $r$ 和下一状态；目标是最大化折扣累计回报。 |
| P0 | 马尔可夫性质是什么？ | 给定当前状态后，未来与过去条件独立，即当前状态已包含预测未来所需的信息。MDP 还包含状态、动作、转移、奖励和折扣因子。 |
| P0 | 状态价值和动作价值有什么区别？ | $V^\pi(s)$ 是从状态出发遵循策略的期望回报；$Q^\pi(s,a)$ 还固定第一步动作。优势函数 $A=Q-V$ 衡量动作相对平均水平。 |
| P0 | Bellman 方程表达了什么？ | 一个状态的价值等于即时奖励与折扣后继价值的期望，把长期回报递归分解为一步问题。 |
| P0 | On-policy 与 Off-policy 的区别？ | On-policy 用当前策略产生的数据学习当前策略；Off-policy 可用其他行为策略的数据学习目标策略，因此能复用经验但需处理分布偏差。 |
| P0 | Monte Carlo 与 Temporal Difference 的区别？ | MC 等 episode 结束后用完整回报更新，无 bootstrap、方差高；TD 用当前估计 bootstrap，可在线更新，偏差更高但方差较低。 |
| P0 | Q-learning 与 SARSA 的区别？ | Q-learning 用下一状态最大 Q 值更新，是 off-policy；SARSA 用行为策略实际选择的下一动作更新，是 on-policy，通常更保守。 |
| P0 | 探索与利用如何权衡？ | 利用选择已知高价值动作，探索获取新信息；常用 $\epsilon$-greedy、熵奖励、UCB、Thompson sampling 或参数噪声。 |
| P0 | 策略梯度的核心思想是什么？ | 直接对期望回报关于策略参数求梯度，用采样轨迹的回报加权 $\nabla\log\pi(a\mid s)$；无需环境可导，但梯度方差较大。 |
| P0 | Actor-Critic 是什么？ | Actor 学策略，Critic 估计价值并为 Actor 提供低方差的优势信号，结合了策略梯度和价值学习。 |
| P0 | PPO 为什么稳定？ | 它用概率比率裁剪或 KL 约束限制新旧策略单次更新幅度，并允许一批 on-policy 数据做多轮 minibatch 更新。 |
| P1 | 奖励稀疏如何处理？ | 可做奖励塑形、课程学习、内在奖励、示范学习、层次化 RL 或更有效探索；塑形要避免改变最优策略或诱发 reward hacking。 |
| P1 | Experience Replay 有什么作用？ | 随机采样历史转移打破时序相关、提升数据复用率并稳定训练；它更适合 off-policy 方法。 |
| P1 | DQN 的 target network 为什么有用？ | 用延迟更新的目标网络计算 bootstrap 目标，减缓“目标随被优化网络同时移动”导致的不稳定。 |
| P2 | Model-based 与 Model-free RL 的区别？ | Model-based 学习或利用环境转移模型进行规划，样本效率高但受模型误差影响；Model-free 直接学价值或策略，通常需要更多交互。 |

## 6. Transformer 与 LLM

| 优先级 | 问题 | 简明答案 |
| --- | --- | --- |
| P0 | Self-Attention 如何计算？ | $Q=XW_Q,K=XW_K,V=XW_V$，输出为 $\mathrm{softmax}(QK^T/\sqrt{d_k})V$；它让每个 token 按相关性聚合其他 token 的信息。 |
| P0 | 为什么除以 $\sqrt{d_k}$？ | 若 Q、K 各维方差近似为 1，点积方差随 $d_k$ 增长；缩放可避免 logits 过大使 softmax 饱和、梯度过小。 |
| P0 | 多头注意力为什么有效？ | 不同头在不同投影子空间并行建模多种关系，再拼接融合；在总隐藏维固定时，每头维度通常相应减小。 |
| P0 | Transformer 为什么需要位置编码？ | 自注意力本身对输入排列等变，无法区分顺序；位置编码向表示或注意力分数注入绝对或相对位置信息。 |
| P0 | 绝对位置编码、相对位置编码和 RoPE 的区别？ | 绝对位置直接加到 token 表示；相对位置建模 token 间距离；RoPE 旋转 Q/K，使点积自然带相对位置信息并常有较好外推。 |
| P0 | Encoder-only、Decoder-only、Encoder-Decoder 的区别？ | Encoder-only 双向注意，适合理解；Decoder-only 因果注意，适合统一生成；Encoder-Decoder 先编码输入再跨注意力生成，适合条件序列转换。 |
| P0 | Causal Mask 做什么？ | 屏蔽当前位置之后的 token，保证训练时每个位置只能看过去，与自回归推理的条件分解一致。Padding mask 则屏蔽补齐位置。 |
| P0 | Transformer block 的主要结构是什么？ | 注意力子层和逐位置 FFN，每个子层配残差与归一化；现代 LLM 常用 Pre-Norm、RMSNorm、SwiGLU 等变体。 |
| P0 | Pre-Norm 与 Post-Norm 的区别？ | Pre-Norm 在子层前归一化，残差主路更直接，深网训练通常更稳；Post-Norm 在残差相加后归一化，是原始 Transformer 形式。 |
| P0 | LayerNorm 与 RMSNorm 的区别？ | LayerNorm 减均值再按标准差缩放；RMSNorm 不减均值，只按均方根缩放，计算更简单。 |
| P0 | FFN 在 Transformer 中的作用？ | 注意力负责 token 间通信，FFN 对每个 token 独立做非线性特征变换，通常承担大量参数与表示容量。 |
| P0 | LLM 的预训练目标是什么？ | Decoder-only LLM 通常最小化下一 token 的负对数似然，即 teacher forcing 下的因果语言建模交叉熵。 |
| P0 | Teacher forcing 与 exposure bias 是什么？ | 训练时用真实历史 token 预测下一 token；推理时依赖自己生成的历史，训练与推理分布不一致形成 exposure bias。 |
| P0 | Tokenizer 的 BPE、WordPiece、Unigram 有何区别？ | BPE 迭代合并高频相邻单元；WordPiece 倾向选择提升语料似然的合并；Unigram 从大词表出发删除低贡献子词。 |
| P0 | Temperature、Top-k、Top-p 如何影响生成？ | Temperature 缩放 logits；Top-k 只保留最高 k 个；Top-p 保留累计概率达到 p 的最小集合。降低它们通常更确定但可能更重复。 |
| P0 | Greedy、Beam Search 与采样怎么选？ | Greedy 每步取最大概率；Beam 保留多条高分序列，适合答案较确定的任务；采样增加多样性，更适合开放生成。 |
| P0 | KV Cache 是什么？ | 自回归解码缓存历史 token 各层的 K/V，新一步只计算新 token，避免重复计算；代价是随 batch、层数和上下文长度增长的显存。 |
| P0 | Prefill 与 Decode 阶段的区别？ | Prefill 并行处理全部输入 token，通常计算密集；Decode 每步生成一个 token，受 KV cache 访存和串行性影响，常为内存带宽密集。 |
| P0 | 为什么长上下文成本高？ | 标准注意力计算和注意力矩阵内存随序列长度近似二次增长，KV cache 随长度线性增长；实际还受 prefill 延迟和检索有效性影响。 |
| P0 | Embedding 与 LM hidden state 有何区别？ | Embedding 是 token 的输入查表向量；hidden state 是经过多层上下文交互后的动态表示，同一 token 在不同上下文会不同。 |
| P1 | MQA 与 GQA 为什么能加速推理？ | MQA 让所有查询头共享一组 K/V，GQA 让一组查询头共享 K/V，显著减小 KV cache 和带宽；GQA 在质量与效率间折中。 |
| P1 | FlashAttention 的核心思想是什么？ | 通过分块和在线 softmax 减少 HBM 与片上 SRAM 间读写，不显式存完整注意力矩阵；它是精确注意力，不是近似算法。 |
| P1 | MoE 的基本原理和挑战？ | 路由器为每个 token 选择少数专家，使总参数量大而单 token 计算受控；挑战包括负载均衡、通信开销、路由不稳和显存占用。 |
| P1 | Scaling Law 说明什么？ | 在一定范围内，模型损失随参数、数据和计算规模呈可预测幂律变化；它用于预算分配，但具体最优比例受数据质量和训练方案影响。 |
| P1 | LLM 为什么会幻觉？ | 训练目标是生成高概率文本而非验证事实，知识可能缺失、冲突或过时，解码和上下文也会诱导错误；RAG、工具、校验与拒答可缓解。 |
| P1 | Perplexity 是什么？ | 是平均负对数似然的指数，表示模型对真实序列的不确定性；只能在 tokenizer 和数据处理可比时比较，且不等同于下游质量。 |
| P2 | Speculative Decoding 如何加速？ | 小模型一次草拟多个 token，大模型并行验证并按规则接受；在保持目标模型分布不变的前提下减少大模型串行解码步数。 |
| P2 | 为什么现代 LLM 常用 SwiGLU？ | 它用门控分支和 SiLU 激活增强 FFN 表达能力，在相近计算预算下常比 ReLU/GELU FFN 效果更好。 |

## 7. 大模型微调与对齐

| 优先级 | 问题 | 简明答案 |
| --- | --- | --- |
| P0 | 预训练、持续预训练和 SFT 的区别？ | 预训练从大规模通用语料学语言能力；持续预训练在领域语料上延续同一目标；SFT 用指令—回答对学习按指令输出。 |
| P0 | Full Fine-tuning 与 PEFT 的区别？ | 全参微调更新全部权重，容量大但显存和存储昂贵；PEFT 只训练少量新增或选定参数，成本低且便于多任务部署。 |
| P0 | LoRA 的原理是什么？ | 冻结原权重，把更新写成低秩矩阵乘积 $\Delta W=BA$，只训练 A、B；推理时可合并回原权重，不增加矩阵乘延迟。 |
| P0 | QLoRA 相比 LoRA 多了什么？ | 将冻结的基础模型以 4-bit 量化存储并把梯度传到 LoRA 适配器，结合 NF4、双重量化和分页优化器进一步省显存。 |
| P0 | 指令微调数据最重要的质量因素？ | 指令覆盖、多样性、答案正确性、格式一致性和难度分布；少量高质量数据常优于大量噪声或模板重复数据。 |
| P0 | RLHF 的典型流程是什么？ | 先 SFT，再用人类偏好对训练奖励模型，最后用 PPO 等优化策略并以 KL 约束避免偏离参考模型过远。 |
| P0 | 奖励模型如何训练？ | 对同一提示的 chosen/rejected 回答打分，用成对排序损失让 chosen 分数高于 rejected；它学习的是标注者偏好代理，不是真实万能奖励。 |
| P0 | DPO 与 PPO-based RLHF 的区别？ | DPO 从偏好数据直接优化策略与参考策略的相对对数概率，无需显式奖励模型和在线 RL 采样，训练更简单稳定；但仍依赖偏好数据和参考模型。 |
| P0 | 对齐中的 KL 约束有什么作用？ | 限制新策略偏离参考模型，防止为追逐奖励而语言退化或 reward hacking；过强会限制学习，过弱可能训练不稳。 |
| P1 | PPO 的 clip objective 在 LLM 对齐中做什么？ | 限制新旧策略概率比率的有效改变量，避免一次更新过大；通常还结合价值损失、熵项和相对参考模型的 KL 惩罚。 |
| P1 | GRPO 与 PPO 的主要差异？ | GRPO 用同一提示的一组采样奖励做组内相对基线估计优势，可省去单独 critic/value model，从而降低对齐训练显存。 |
| P1 | Preference data 有哪些常见偏差？ | 位置偏差、长度偏好、文风偏好、标注者群体偏差和难例覆盖不足；需随机化顺序、统一准则、质检并保留分歧信息。 |
| P1 | Catastrophic forgetting 如何缓解？ | 混入通用数据、降低学习率、使用 PEFT、正则约束参数变化，并同时评估领域能力与通用基准。 |
| P1 | Fine-tuning 与 RAG 怎么选？ | 改变行为、格式、风格或稳定技能更适合微调；注入可更新、可引用的外部知识更适合 RAG；生产中常组合使用。 |
| P2 | Reward hacking 是什么？ | 策略找到提高代理奖励但违背真实目标的捷径。需改进奖励、加入规则与审计、对抗评测，并限制策略偏移。 |

## 8. RAG

| 优先级 | 问题 | 简明答案 |
| --- | --- | --- |
| P0 | RAG 的基本流程是什么？ | 文档解析与切块 → 向量化和建索引 → 查询改写/向量化 → 召回 → 重排 → 把证据放入提示 → 生成并引用。 |
| P0 | 已有强大 LLM 为什么还需要 RAG？ | RAG 能接入私有或最新知识、提供可追溯证据并降低参数化记忆压力；但它不能保证不幻觉，检索和生成仍需评估。 |
| P0 | Chunk size 和 overlap 如何选择？ | 块太小语义不完整，太大则噪声多并挤占上下文；overlap 保留跨边界信息但增加存储和重复召回。应按文档结构与评测调优。 |
| P0 | 稠密检索与稀疏检索的区别？ | 稠密检索用 embedding 捕获语义相似；BM25 等稀疏检索擅长精确词、编号和专有名词。混合检索常比单一路径稳健。 |
| P0 | 向量相似度常用哪些指标？ | 常用余弦相似度、点积和欧氏距离。向量归一化后，最大化余弦与点积排序等价，欧氏距离排序也有简单对应。 |
| P0 | Bi-encoder 与 Cross-encoder 的区别？ | Bi-encoder 独立编码查询和文档，可预计算并大规模召回；Cross-encoder 联合编码二者，交互充分但慢，常用于小候选集重排。 |
| P0 | 为什么召回后还要 rerank？ | ANN 或稀疏召回强调速度，相关性估计较粗；重排器对较少候选做更强的查询—文档交互，提高前几名证据质量。 |
| P0 | 如何评估 RAG？ | 分层评估检索 Recall@K、MRR、NDCG；生成端评估答案正确性、faithfulness、引用准确率和拒答；最后用端到端任务成功率、延迟与成本。 |
| P0 | RAG 幻觉如何定位？ | 区分未召回正确证据、重排失败、上下文有证据但模型没用、证据冲突、问题不可答等环节，逐层保存日志和构造有标注评测集。 |
| P1 | Query rewriting 有什么作用？ | 把含糊、多轮或口语查询改写为适合检索的独立查询，也可生成多个子查询提高覆盖；需防止改写偏离原意。 |
| P1 | HyDE 是什么？ | 先生成一个假想答案或文档，再用其 embedding 检索真实文档；可弥合短查询与长文档语义差距，但假想内容错误会带偏检索。 |
| P1 | 多跳问题如何做 RAG？ | 将问题拆成依赖子问题，按步骤检索并把中间结论用于下一跳；可用图检索或 Agent 编排，但需控制误差累积。 |
| P1 | 长上下文是否会取代 RAG？ | 不完全。长上下文减少切块与召回需求，但输入成本、延迟、知识更新、权限过滤和“中间信息遗失”仍使 RAG 有价值。 |
| P1 | 如何处理文档更新与删除？ | 保留文档 ID、版本、chunk 血缘和时间戳，增量重建受影响块；删除时同步清理向量、缓存和派生索引，避免幽灵数据。 |
| P1 | RAG 如何做权限控制？ | 在检索层按用户/租户权限过滤，不能仅靠提示词；索引、缓存、日志与引用都要继承 ACL，且防止跨租户向量泄漏。 |
| P2 | Graph RAG 适合什么问题？ | 适合实体关系、多跳推理和全局主题总结；代价是实体抽取、图构建和更新复杂，不应在普通语义检索足够时盲目使用。 |

## 9. Agent

| 优先级 | 问题 | 简明答案 |
| --- | --- | --- |
| P0 | 什么是 LLM Agent？ | 由模型根据目标动态决定步骤和工具调用，在“观察—决策—行动—再观察”循环中推进任务的系统；固定代码路径更准确地称为 workflow。 |
| P0 | Agent 与普通 Chatbot 的区别？ | Chatbot 主要生成回复；Agent 还能维护任务状态、选择工具并影响外部环境，因此能力更强，同时风险、延迟和评测难度也更高。 |
| P0 | ReAct 模式是什么？ | 交替进行 reasoning 与 action：模型根据当前观察选择工具，读取结果后再决定下一步，直到给出答案或终止。 |
| P0 | Agent 的核心组件有哪些？ | 模型、指令/目标、工具、上下文与状态、短期/长期记忆、规划与执行循环、终止条件、权限和评测观测。 |
| P0 | 如何设计好工具？ | 单一职责、清晰命名和描述、严格输入 schema、结构化输出、明确错误语义和幂等性；高风险工具还需权限、确认和审计。 |
| P0 | Function calling 的工作流程？ | 把工具 schema 提供给模型；模型输出工具名和参数；宿主校验并执行；结果作为新上下文返回模型，模型继续决策或生成最终答案。 |
| P0 | MCP 是什么？ | 一种基于客户端—服务器的开放协议，标准化 AI 应用发现和使用 tools、resources、prompts；它解决接入方式，不自动解决权限和安全。 |
| P0 | Agent memory 有哪些类型？ | 工作记忆保存当前任务上下文；情节记忆记录历史交互；语义记忆保存抽取知识。长期记忆通常需检索、压缩、过期和权限策略。 |
| P0 | Workflow 与 Agent 怎么选？ | 步骤已知、要求稳定可审计时用 workflow；路径无法预先穷举且需要模型灵活决策时用 Agent。优先选择满足需求的最低复杂度。 |
| P0 | Prompt injection 为什么对 Agent 更危险？ | 恶意指令可藏在网页、邮件或检索文档中，诱导模型滥用工具；Agent 有外部行动能力，因此影响从错误文本扩大到数据或系统操作。 |
| P0 | 如何降低 Agent 工具调用风险？ | 最小权限、输入输出校验、隔离不可信内容、读写工具分离、危险操作人审、沙箱、预算与超时、幂等和完整审计日志。 |
| P0 | 如何评估 Agent？ | 用真实任务集评估最终成功率，并分解工具选择、参数正确性、步骤效率、恢复能力、安全违规、成本和延迟；随机系统需多次运行。 |
| P1 | Planner-Executor 架构的优缺点？ | 规划器生成或更新计划，执行器逐步调用工具，便于观察和分工；但计划可能很快过时，需允许基于新观察重规划。 |
| P1 | 单 Agent 与多 Agent 怎么选？ | 单 Agent 更简单、上下文一致、成本低；只有角色专业化、可并行或需要独立校验带来明确收益时才用多 Agent。 |
| P1 | 多 Agent 的主要失败模式？ | 通信丢失或放大错误、角色重叠、循环争论、共享记忆污染、责任不清和成本爆炸；需要协议、终止条件和集中可观测性。 |
| P1 | Agent 如何避免死循环？ | 设置最大步数、时间和 token/费用预算；检测重复状态或相同工具调用；工具返回明确错误；失败后降级或请求人工输入。 |
| P1 | Agent 状态为什么要与聊天记录分开？ | 聊天文本不适合可靠表示任务机、权限、已完成步骤和结构化结果；显式状态便于恢复、并发控制、验证和审计。 |
| P1 | Agent 的 human-in-the-loop 应放在哪里？ | 在高影响、不可逆、超权限或低置信操作前确认，而不是所有步骤都打断；审批界面应展示将执行的动作、参数和影响。 |
| P1 | 如何处理工具失败？ | 区分可重试与永久错误，采用超时、有限指数退避、幂等键和熔断；把结构化错误反馈给模型，并允许换工具、改参数或降级。 |
| P2 | Evaluator-Optimizer 模式是什么？ | 一个模型产出，另一个按明确标准评分反馈，再迭代改进；适合评价标准清晰且提升值得额外延迟与成本的任务。 |

## 10. 训练、推理与 MLOps

| 优先级 | 问题 | 简明答案 |
| --- | --- | --- |
| P0 | 一个标准 ML 工程流水线有哪些环节？ | 数据采集与版本化、清洗和特征、训练、离线评估、模型注册、部署、在线实验、监控、反馈与再训练。 |
| P0 | 数据并行与模型并行的区别？ | 数据并行复制模型、切分 batch 并同步梯度；模型并行切分单个模型，常含张量并行、流水线并行与参数/状态分片。 |
| P0 | DDP 如何同步梯度？ | 每个进程持有模型副本并处理不同数据，反向时通过 all-reduce 聚合梯度，使各副本更新一致；通常一张 GPU 对应一个进程。 |
| P0 | 梯度累积有什么用？ | 连续多个 micro-batch 反传后再更新，模拟更大有效 batch；损失需按累积步数缩放，但它不会减少一次样本总计算。 |
| P0 | 混合精度训练为什么更快？ | 在适合的算子使用 FP16/BF16，减少显存和带宽并利用 Tensor Core；关键累加或参数可保留高精度。FP16 常需 loss scaling 防下溢。 |
| P0 | FP16 与 BF16 的区别？ | FP16 尾数更多但指数范围小，易溢出/下溢；BF16 指数范围接近 FP32、训练更稳，但单值精度略低。 |
| P0 | Gradient Checkpointing 的原理？ | 前向只保存部分激活，反向时重算缺失部分，以额外计算换显存；不减少参数和优化器状态。 |
| P0 | 训练 OOM 如何排查？ | 先分清参数、梯度、优化器状态、激活或碎片导致；再减 micro-batch/序列长、开混合精度与 checkpoint、分片状态或采用 PEFT。 |
| P0 | 量化是什么？ | 用更低位宽表示权重和/或激活以降低显存、带宽和计算；PTQ 训练后量化成本低，QAT 在训练中模拟量化通常精度更好。 |
| P0 | 吞吐量与延迟有什么区别？ | 延迟是单请求完成时间，吞吐量是单位时间处理量；加大 batch 常提升吞吐但可能增加排队和单请求延迟。 |
| P0 | Continuous Batching 是什么？ | 不等整批请求一起结束，而在每个解码步动态加入新请求、移除已完成请求，提高 GPU 利用率和总体吞吐。 |
| P0 | PagedAttention 解决什么问题？ | 将 KV cache 分页管理，减少连续大块预留造成的碎片和浪费，允许更灵活共享与调度 KV 内存。 |
| P0 | 线上模型要监控什么？ | 服务层监控错误率、延迟、吞吐和资源；数据层监控 schema、缺失和漂移；模型层监控质量、校准、偏差及业务指标。 |
| P0 | A/B 测试的核心注意点？ | 先定义主指标与护栏指标，随机稳定分流，估算样本量并控制实验时长；避免窥视、网络效应和多个实验相互污染。 |
| P1 | 训练结果如何保证可复现？ | 固定并记录随机种子、数据/代码/依赖/硬件版本和全部配置；但并行浮点归约及非确定性内核仍可能造成微小差异。 |
| P1 | Feature Store 解决什么问题？ | 复用和治理特征，保持离线训练与在线服务定义一致并支持时间点正确回放；它不能自动消除错误特征或泄漏。 |
| P1 | 模型发布常见策略有哪些？ | Shadow 只旁路观测；Canary 小流量验证；Blue-Green 在两套环境间切换；都应配自动指标检查和快速回滚。 |
| P1 | 缓存如何用于 LLM 服务？ | 可缓存完全相同请求、共享 prompt prefix 的 KV、检索结果和工具结果；必须考虑租户隔离、版本、时效性及非确定生成。 |
| P1 | Tensor Parallel 与 Pipeline Parallel 的区别？ | TP 把单层矩阵运算切到多设备，通信频繁；PP 把不同层放不同设备，以 micro-batch 填流水线但存在气泡。 |
| P2 | 为什么 GPU 利用率高不一定服务好？ | GPU 忙可能来自过大 batch 或无效计算，同时用户排队延迟很高；必须联合观察 token 吞吐、TTFT、TPOT、队列和成本。 |
| P2 | TTFT 与 TPOT 分别是什么？ | TTFT 是请求到首 token 的时间，受排队和 prefill 影响；TPOT 是生成阶段每个输出 token 的平均时间，主要反映 decode 性能。 |

## 11. Python、SQL 与计算机基础

| 优先级 | 问题 | 简明答案 |
| --- | --- | --- |
| P0 | Python 的 list 与 tuple 有何区别？ | list 可变，tuple 不可变；tuple 可在元素均可哈希时作为字典键，通常也更轻量。是否选择它们主要取决于语义和可变性。 |
| P0 | 浅拷贝与深拷贝的区别？ | 浅拷贝只复制外层容器，内部可变对象仍共享；深拷贝递归复制对象图。二者对不可变对象可能表现相同。 |
| P0 | Python 可变默认参数有什么坑？ | 默认参数在函数定义时只创建一次，多次调用会共享同一对象。通常用 `None` 作默认值并在函数内新建容器。 |
| P0 | 迭代器与生成器是什么？ | 迭代器实现逐项访问协议；生成器用 `yield` 惰性地产生值并保存执行状态，适合流式数据和降低峰值内存。 |
| P0 | Python GIL 是什么？ | CPython 的全局解释器锁使同一进程通常只有一个线程执行 Python 字节码；I/O 密集线程仍有用，CPU 密集任务常用多进程或释放 GIL 的原生算子。 |
| P0 | 进程、线程和协程的区别？ | 进程隔离强、切换和通信成本高；线程共享进程内存；协程由用户态事件循环协作调度，适合大量 I/O 并发而非直接加速 CPU 计算。 |
| P0 | 死锁的四个必要条件？ | 互斥、持有并等待、不可抢占、循环等待。破坏任一条件，或用锁顺序、超时和检测恢复，可预防或缓解死锁。 |
| P0 | TCP 与 UDP 的区别？ | TCP 面向连接、可靠、有序并带流量/拥塞控制；UDP 无连接、不保证到达和顺序，头部小、时延可控，可靠性可由应用层实现。 |
| P0 | TCP 为什么三次握手？ | 双方需确认彼此收发能力并同步初始序列号；第三次确认让服务端知道客户端已收到自己的序列号，避免失效请求造成误连接。 |
| P0 | HTTP 与 HTTPS 的区别？ | HTTPS 是 HTTP 运行在 TLS 之上，通过证书认证、密钥协商和加密完整性保护，防止窃听和篡改。 |
| P0 | 数据库索引为什么能加速查询？ | B+ 树或哈希索引减少扫描范围；代价是额外存储和写入维护。联合索引能否命中与列顺序、谓词和排序有关。 |
| P0 | `WHERE` 与 `HAVING` 的区别？ | `WHERE` 在分组聚合前过滤行；`HAVING` 在 `GROUP BY` 后过滤组。能提前过滤的条件通常放 `WHERE`。 |
| P0 | INNER JOIN 与 LEFT JOIN 的区别？ | INNER JOIN 只保留两侧匹配行；LEFT JOIN 保留左表全部行，右侧无匹配时填 NULL。 |
| P0 | 哈希表的平均和最坏复杂度？ | 查找、插入平均 $O(1)$；严重冲突时最坏可到 $O(n)$，取决于哈希函数、装载因子和冲突处理方式。 |
| P0 | 堆适合解决什么问题？ | 堆可在 $O(1)$ 查看极值、$O(\log n)$ 插入删除，适合 Top-K、优先队列和流式中位数等问题。 |
| P1 | 装饰器是什么？ | 接收函数或类并返回包装后对象，用于日志、缓存、鉴权等横切逻辑；应使用 `functools.wraps` 保留元数据。 |
| P1 | 虚拟内存有什么作用？ | 为进程提供独立连续地址空间，通过页表映射物理内存并支持按需分页、隔离和共享；缺页会触发较昂贵的系统处理。 |
| P1 | I/O 多路复用是什么？ | 用 `select/poll/epoll` 等让单线程等待多个文件描述符就绪，再处理事件；适合大量连接但单次任务较轻的场景。 |
| P1 | 幂等性是什么？ | 同一操作执行一次或多次，对系统最终状态的影响相同。重试写请求时常用幂等键避免重复扣款、建单或工具副作用。 |
| P1 | SQL 窗口函数有什么用？ | 在保留每行的同时计算分组排名、累计值、移动平均等，例如 `ROW_NUMBER() OVER (PARTITION BY ... ORDER BY ...)`。 |

## 12. 手撕代码与数学推导

> 手撕题不只要说思路：先确认输入与边界，再给复杂度，最后用空输入、单元素、重复值和极端值自测。

| 优先级 | 问题 | 简明答案 |
| --- | --- | --- |
| P0 | 手写二分查找。 | 明确闭区间 `[l,r]` 或左闭右开 `[l,r)` 并始终保持不变量；每轮排除一半，时间 $O(\log n)$、空间 $O(1)$。 |
| P0 | 反转单链表。 | 迭代维护 `prev, cur, next` 并逐条反转指针，时间 $O(n)$、空间 $O(1)$；也应能说明递归版本。 |
| P0 | 求 Top-K 大元素。 | 小顶堆维护 K 个元素，时间 $O(n\log k)$、空间 $O(k)$；离线且允许改数组可用 quickselect，平均 $O(n)$。 |
| P0 | 合并区间。 | 按左端点排序，依次与结果最后区间判断重叠并扩展右端点；时间主要为排序 $O(n\log n)$。 |
| P0 | LRU Cache 如何实现？ | 哈希表提供 $O(1)$ 定位，双向链表维护新旧顺序；访问或更新移到表头，超容量淘汰表尾。 |
| P0 | 编辑距离的动态规划如何定义？ | `dp[i][j]` 表示前 i、j 个字符的最小编辑数；相等沿用左上，否则取插入、删除、替换三者最小值加一，时间 $O(mn)$。 |
| P0 | 手写稳定版 softmax。 | 先减每行最大 logit，再指数化并除以指数和，防止上溢；`log_softmax` 用 log-sum-exp 可进一步稳定。 |
| P0 | 手写交叉熵要注意什么？ | 对正确类别取负对数概率；实现时优先从 logits 用 log-sum-exp 计算，避免先 softmax 后 `log(0)`。 |
| P0 | 推导线性回归正规方程。 | 令 $\lVert Xw-y\rVert^2$ 对 $w$ 的梯度为零，得 $X^TXw=X^Ty$；可逆时 $w=(X^TX)^{-1}X^Ty$，工程上通常用 QR/SVD 而不显式求逆。 |
| P0 | 推导 sigmoid + BCE 对 logit 的梯度。 | 对单样本，$L=-y\log\sigma(z)-(1-y)\log(1-\sigma(z))$，化简得 $\partial L/\partial z=\sigma(z)-y$。 |
| P0 | 推导 softmax + 交叉熵的梯度。 | 对 logits $z$，梯度为预测概率减 one-hot 标签，即 $\partial L/\partial z_i=p_i-y_i$。 |
| P1 | 用 NumPy 实现二维卷积要注意什么？ | 明确 batch/channel 格式、padding、stride、kernel 翻转约定和输出尺寸；朴素循环正确后可用 im2col + GEMM 向量化。 |
| P1 | 实现 k-means。 | 随机或 k-means++ 初始化中心，交替分配样本与更新均值；处理空簇、停止条件和随机种子，并对特征先缩放。 |
| P1 | 手写 scaled dot-product attention。 | 计算 $QK^T/\sqrt d$，在 softmax 前加入 causal/padding mask，再乘 V；要检查 batch、head、sequence 维度和全 mask 行。 |
| P1 | Reservoir Sampling 解决什么问题？ | 从未知长度流中均匀抽 K 个样本：前 K 个入池，第 i 个以 K/i 概率入池并随机替换，空间 $O(K)$。 |

### 13.1 项目追问

| 优先级 | 问题 | 简明答案 |

| P0 | 请用两分钟介绍最重要的项目。 | 按“问题与约束—你的职责—方案—关键难点—量化结果—复盘”讲；先给结论，避免从技术细节或团队背景流水账开始。 |
| P0 | 为什么选这个模型而不是更简单/更复杂的方案？ | 从数据量、任务结构、基线、延迟成本、可解释性和实验结果说明选择；必须能给出备选方案及取舍。 |
| P0 | 数据从哪里来，如何切分？ | 说明采集、清洗、标注、去重与版本；切分单位要避免同用户/同主体泄漏，时间敏感任务按时间做回放。 |
| P0 | 你的 baseline 是什么？ | baseline 应简单、可复现且与目标指标一致；新方法的收益要在同数据、同预算和同评估协议下比较。 |
| P0 | 做了哪些消融实验？ | 逐一移除或替换关键组件，证明每个设计对核心指标的独立贡献，并报告随机波动或多次运行结果。 |
| P0 | 遇到的最大失败是什么？ | 说清现象、定位过程、根因、修复和防复发措施；重点展示可验证的排障方法，不要只说“调参解决”。 |
| P0 | 指标提升是否有统计或业务意义？ | 报绝对值、相对值、方差/置信区间和数据规模，并说明离线指标如何映射到线上收益及护栏指标。 |
| P1 | 如果数据量或流量扩大 100 倍怎么办？ | 分析先失效的瓶颈，再讨论数据分片、近似算法、批处理/流处理、缓存、并行训练与降级，而不是笼统回答“加机器”。 |
| P1 | 项目中你个人的贡献如何证明？ | 区分团队结果和个人负责模块，给出你提出的决策、实现、实验或事故处理证据，并说明与他人的接口。 |
| P1 | 如果再做一次会改什么？ | 选择真实且有影响的改进，如先建评测、减少复杂组件、修正数据切分或补监控，并说明为何当时没有这样做。 |

| P1 | 设计一个能操作外部系统的 Agent。 | 明确任务边界，用最少工具和显式状态机；工具做 schema 校验、最小权限、幂等和审计，高风险动作人审，最后用真实任务和攻击集评测。 |
| P1 | 如何选择在线与离线推理？ | 低延迟、依赖实时输入用在线；可批处理且时效宽松用离线以提高吞吐和成本效率；很多系统采用离线预计算加在线轻量更新。 |
| P1 | 没有足够标签怎么办？ | 从规则和弱监督建立 baseline，主动学习优先标难例，利用预训练/自监督/迁移学习，并设计高质量小规模人工评测集。 |
